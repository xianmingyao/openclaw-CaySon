## 🔥 本月最大风口：子 Agent 编排

### 1. 子 Agent 是什么？
**定义**：在一个主 Agent 内部，可以拆出的"子任务执行者"。Loop Engineering 的核心组件之一。

### 2. 5 个核心模块（Claude Code / Codex 已全部支持）

| 模块 | 作用 |
|------|------|
| **Automations** | 自动化触发器（定时/事件） |
| **Worktrees** | Git worktree 隔离并行工作 |
| **Skills** | 可复用技能包（SKILL.md） |
| **Connectors** | 外部连接器（MCP / API） |
| **Sub-agents** | 子智能体（递归任务拆分） |

### 3. 实战铁律

```bash
# /goal 命令：定义可机器校验的目标
/goal "确保所有商品图片上传成功" \
  --check "image_count == 50" \
  --max-tokens 50000 \
  --worktree feature/images-v2
```

**关键设计原则**：
- ✅ 用 `/goal` 机器可校验条件（不要"尽量"、"大概"）
- ✅ 拆分 maker 和 checker（不能自己审自己）
- ✅ 状态写磁盘（模型会忘，磁盘不会）
- ✅ token 上限（避免"无限打转"）
- ✅ 读 loop 输出（人工把关最后环节）

### 4. 经典案例：Ralph Wiggum 自进化循环
- **来源**：Claude Code best practice 仓库
- **特点**：完整可克隆运行的 repo
- **价值**：自进化的最小可行循环

## 🕳️ 避坑提醒

### 🔴 坑1：Sora 死了，但 Sora API 还活着
- app/web 已下线（4-26）
- API 仍可用，但成本可能上调
- 别把鸡蛋全放 OpenAI 篮子里

### 🔴 坑2：中国军团虽强，但生态不同
- Qwen / DeepSeek / GLM 国内访问友好
- 海外业务仍首选 Claude / GPT / Gemini
- ELUCKY 跨境业务需要"双轨模型栈"

### 🔴 坑3：子 Agent ≠ 多 Agent
- **子 Agent**：在同一主 Agent 内递归拆任务（共享上下文）
- **多 Agent**：独立 Agent 通过协议协作（独立上下文）
- 别混淆概念，架构差异巨大

### 🔴 坑4：Loop Engineering 不是万能药
- 需要清晰的 `/goal` 可校验条件
- 需要 maker/checker 分离
- 需要磁盘状态持久化
- **没有这三条 = 跑不起来的循环**
