## 🥈 2. VoxCPM - TTS 革命（清华 OpenBMB 出品）

### 基本信息
- **作者**：OpenBMB（清华团队）
- **仓库**：https://github.com/OpenBMB/VoxCPM/
- **官网**：https://voxcpm.space/
- **Demo**：https://openbmb.github.io/VoxCPM-demopage/
- **最新版本**：VoxCPM2（2B 参数）

### 核心创新：无 Tokenizer TTS
- ❌ 传统 TTS：文本 → Token → 声学模型 → 语音
- ✅ VoxCPM：文本 → 连续语音表示（端到端扩散自回归）
- **优势**：跳过离散 token 化，自然度和表达力大幅提升

### 三大能力
1. **上下文感知语音生成** —— 不是逐句拼接，而是连贯的整段语音
2. **零样本声音克隆** —— 几秒钟样本即可克隆任意声音
3. **多语言 TTS** —— 训练数据 180 万小时中英双语

### 适用场景
| 场景 | 价值 |
|------|------|
| **ELUCKY 短视频配音** | 一键克隆主播声音，多语言适配 |
| **跨境电商解说** | 英文/西班牙语/葡萄牙语 TTS |
| **抖音/TikTok 自动化** | 视频 + 配音全自动化 |
| **京麦商品描述** | 商品介绍音频化 |

## 🏅 4. Hermes Agent - 自然语言设计 Agent 团队

### 核心创新
**"用自然语言设计 Agent 团队"** —— 不用写代码，用描述就能组建 Agent 团队。

### 两大版本
1. **Hermes Agent** —— 桌面/服务器端 Agent 团队
2. **Hermes Webb** —— **手机上运行**的 Agent 团队

### 实战示例
```python
harness = HermesHarness()
team = harness.design_team("""
需要一个跨境电商运营团队：
- 内容创作 Agent：写英文商品描述
- 视频生成 Agent：制作 TikTok 短视频
- 评论管理 Agent：自动回复客户
- 数据分析 Agent：跟踪销售数据
""")
team.run()
```

## 🕳️ 避坑提醒

### 🔴 坑1：ECC 是"瑞士军刀"不是"手术刀"
- ECC 通用但不够垂直
- 你应该 fork 后砍掉不适用的部分
- 别试图"全用 ECC"，要做减法

### 🔴 坑2：VoxCPM 中文强但英文弱
- 训练数据偏中英双语
- 小语种（葡语/阿语）需要再训练
- 跨境到欧洲市场要慎用

### 🔴 坑3：MoneyPrinterTurbo 素材版权
- 自动检索的素材可能有版权问题
- ELUCKY 商用前必须审核
- 建议加一层素材白名单

### 🔴 坑4：Headroom 不是无损压缩
- 95% 压缩率下"答案不变"是统计意义上的
- 极端 case 可能丢失关键信息
- 京麦关键字段不能压缩
