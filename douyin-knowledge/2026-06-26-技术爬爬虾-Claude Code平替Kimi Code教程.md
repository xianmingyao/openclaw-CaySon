## 📝 核心信息

### 一、为什么是 Kimi Code？

**最大优势**（4个）：
- ✅ **不需翻墙**（国内用户友好）
- ✅ **一行命令安装**
- ✅ **内置最新开源模型 Kimi K2.7 Code**
- ✅ **支持自由切换不同供应商和模型**

**编程能力**：K2.7 Code 比 K2.6 有**真实提升**，**进一步缩小与国外一线模型的差距**。

### 二、特色功能（6 大亮点）

#### 1️⃣ 视频理解（ReadMediaFile）
内置工具，**直接把视频拖进 Kimi Code** 即可分析。

**实战案例**：2022 卡塔尔世界杯视频
- 识别出比赛年份和对阵双方
- 自动标注 8 个进球的时间
- 把 8 个进球剪成 40 秒精彩集锦
- 配背景音乐

#### 2️⃣ 官方数据插件（Kimi Data Source）
**6 种数据源**：股票 / 企业工商信息 / 学术文献 / 等

**实战案例**：绘制黄金/白银/美股/A股/港股近一年归一化走势图。

#### 3️⃣ 3 种工作模式

| 模式 | 命令 | 特点 | 适用场景 |
|------|------|------|----------|
| **Auto** | `/auto` | 工具调用+文件修改自动审批 | **默认推荐**（高安全+高便利）|
| **YOLO** | `/yolo` | 跳过所有审批 | 7.5 分钟完成大任务（熟悉任务用）|
| **Go** | `/go` | K2.7 专门优化 | 多轮迭代（需配 Playwright 验证）|

#### 4️⃣ 群组模式（Swarm）
**能力**：将大任务**拆分成子任务** → **并行处理** → **整合最终结果**。

**实战案例**：6 篇 AI 论文 → 统一视觉风格 → 制作复杂风格专题页
- 主 agent 启动 3 个 subagent swarm
- 分头下载 6 篇论文
- 主 agent 再次启动 swarm，分配 3 个 subagent
- 分头制作专题页
- 主 agent 汇总

**效果**：编码效率提高，每篇论文配独特主题色，风格统一。

#### 5️⃣ Go 模式（多轮迭代）
**适用条件**：
- 任务需要**多轮迭代**
- 有**可验证方法**（如 Playwright 截图）
- 有**明确目标**（如"画面越来越好"）

**实战案例**：青蛙过河游戏
- 14 分钟，5 轮迭代
- 用 Playwright CLI 测试 + 保留每轮截图
- 画面质感越来越好

#### 6️⃣ btw 命令（临时子 agent）
- 临时生成子 agent
- 能看到当前对话历史
- **但不会修改上下文 + 不会调用工具**
- 适合临时提问技术问题

### 三、Skills 系统

**Skills = 给 agent 的专业技能包（带目录的说明书）**

**实战案例**：Playwright CLI 浏览器自动化 skill
1. 创建项目文件夹
2. 配置 Playwright CLI + 对应 skill
3. **⚠️ 重要：Skills 文件夹名必须是 `.agents`（不是 `.cloud`）**
4. 启动测试：输入"使用 Playwright 打开谷歌，搜索青岛天气"

### 四、性能对比（Kimi K2.7 Code vs Claude Opus 4.8）

**测试任务**：修 4.5 Anstar 企业级日程管理系统（1000+ 文件，72 万行代码）的周视图 bug

| 指标 | Kimi K2.7 Code | Claude Opus 4.8 |
|------|----------------|-----------------|
| 上下文占用 | 7.5k（13% 窗口） | - |
| 用时 | < 8 分钟（1 轮） | 8 分钟 + 2 轮 |
| 一次性成功率 | ✅ 一次成功 | ❌ 需调高思考强度 + 2 轮 |
| Token 用量 | 260 万 token | - |
| **缓存命中率** | **97%** | 无法统计 |
| **总成本** | **明显低于** | 高 |

**97% 缓存命中率的意义**：
- 很好地复用上下文
- 成本更低
- 上下文利用更充分
- 多轮协作更稳定
- **更适合处理大型代码库和长流程开发**

### 五、IDE 集成（Z IDE + ACP 协议）

**ACP = Agent Communication Protocol**（智能体通信协议）

> Kimi Code 原生支持 ACP 协议，**给代码编辑器和编程 agent 之间协作的通信协议**。

**以 Z IDE 为例的集成步骤**：
1. 安装 Z（IDE）
2. 打开 Z
3. 右上角三个点 → add custom agent
4. 把 ouragent 段替换成 Kimi code 配置
5. 保存
6. 回到 agent 面板，打招呼测试
7. 收到回复 → 配置成功

**效果**：一边跟 AA 对话，一边查看修改代码。
