## 🎯 视频摘要

**核心理念**：skill 装多了容易"弱"（用不上、用不精），所以宁少勿多。

博主装了上百个 Claude Code skill，最后按场景只留 **11 个** 真正高频使用的，分成 **3 大类**：

| 大类 | skill 数量 | 核心目的 |
|------|-----------|----------|
| 效率工具 | 5 | 提效率（信息获取 + 流程自动化） |

## 📝 11 个 Skill 清单

### 🟢 第一类：效率工具（5个）

#### 1️⃣ Agent Reach
- **作用**：跨平台资料收集（YouTube / 小红书 / Twitter / 公众号）
- **亮点**：自然语言一句话描述需求，自动跨平台搜索 + 提取字幕
- **价值**：**不花 API 费用**（对比 OpenAI API 调字幕接口）

#### 2️⃣ LM Skill（终端内资料分析）
- **作用**：在终端（Claude Code）里直接操控本地资料
- **场景**：批量导入 → 自动归纳分析
- **特点**：不用打开专门软件，命令行里直接搞定

#### 3️⃣ Browser Use（浏览器自动化）
- **作用**：让 AI 直接接管你的 Chrome 浏览器
- **能力**：打开网页、点按钮、填表单、截图、爬数据
- **价值**：跟人坐在电脑前操作没区别，每天重复的流程丢给它就行

#### 4️⃣ Skill Creator
- **来源**：Anthropic 官方出品
- **定位**：**写 skill 的 skill**（meta-skill）
- **用法**：把每天重复的工作流用一句话描述出来 → 自动封装成可复用的 skill
- **博主评价**：**"这个 skill 长期价值会非常非常高"** ⭐

#### 5️⃣ Find Skills（skill 搜索引擎）
- **作用**：skill 的智能检索 / 路由引擎
- **场景**：你不知道该用哪个 skill 时，告诉它你的需求 → 它根据上下文自动找最合适的
- **价值**：不用自己一个一个翻

---

### 🔵 第二类：成品开发（5个）

#### 6️⃣ GStack（含 office hours）
- **来源**：硅谷创业圈（Y Combinator 风格）开源技能库
- **核心 sub-skill**：**office hours**
- **用法**：做任何事之前，先让 AI 联问 6 个问题，把目标和约束条件逼出来
- **博主评价**：用的**最多**的子功能
- **效果**：跳过这一步做出来的东西，返工率高很多

#### 7️⃣ Superpowers
- **作用**：给 Claude Code 装一套**工程师工作习惯**
- **内容**：拆任务、写测试、代码审查
- **特点**：这些流程默认就会走，**不用你每次提醒**
- **本质**：把 AI 编程从"能跑就行"推到"可以交付"

#### 8️⃣ Frontend Design（前端设计从0到1）
- **场景**：从零生成页面前端设计
- **特点**：你不懂设计没关系，排版配色、交互细节，它自己判断

#### 9️⃣ UI/UX Pro Max（前端设计优化）
- **场景**：在现有页面基础上做优化
- **配对使用**：8️⃣ 负责"从 0 到 1"，9️⃣ 负责"从 1 到 100"

#### 🔟 Playwright MCP
- **作用**：**自动化测试**
- **用法**：产品做完后，让 AI 模拟用户操作跑一遍
- **能力**：哪里点不动、哪里报错，全部给你爆出来
- **价值**：**不用自己手动一个一个点**

---

### 🟣 第三类：自媒体（1个）

#### 1️⃣1️⃣ Humanizer（keymenizer.zh）
- **作者**：规则大佬出品
- **问题**：AI 写的东西通顺但"读起来不像人话"
- **作用**：专门处理 AI 文本人性化问题
- **效果**：过一遍之后，自然度明显不一样
- **博主评价**：虽然只有一个，**但几乎每天都在用**（做内容的都用得上）

### 💡 三个高价值点

1. **Skill Creator（meta-skill）**：把"每天重复的工作流"变成一句话 → 自动封装成可复用 skill。这跟我们 MANY skills 散装的痛点完全相反
2. **GStack office hours**：6 个问题逼出目标和约束。**这就是 Mom Test 的 AI 版本**（之前 Mom Test 已学）
3. **三线覆盖 90% 场景**：效率（信息+流程）+ 成品（工程+设计+测试）+ 内容（人性化）。这个分类法比按工具分（浏览器/MCP/搜索）更实用

### 🔴 视频本身的局限性

- **没有截图/字幕**（盲转录），11 个 skill 名称是结合上下文 + 行业常见工具推断，**可能有 1-2 个名称偏差**
- **博主身份是培训圈**（江学长 ai 学习圈 2000+ 人），不一定是工程师视角
- **没有版本号 / 评分 / GitHub star**，无法独立验证

### 🎬 建议宁兄的下一步

1. **优先装这 3 个**（性价比最高）：
   - Skill Creator（meta-skill，长期价值）
   - GStack（office hours 跟 Mom Test 互补）
   - Humanizer（京麦商品描述、抖音文案都用得上）
2. **暂缓评估**：Frontend Design / UI/UX Pro Max（宁兄目前不是做 UI 的）
3. **直接复用宁兄已有的**：Browser Use（agent-browser）、Playwright MCP（与京麦自动化方向一致）
