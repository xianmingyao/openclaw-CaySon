### 2. ⭐ MemPalace/mempalace
**一句话**：本地优先 AI 记忆系统，96.6% 检索召回率，零 API 调用

**项目档案**：
- **GitHub**：https://github.com/MemPalace/mempalace
- **PyPI**：https://pypi.org/project/mempalace/
- **文档**：https://mempalaceofficial.com
- **License**：开源

**是什么**：
本地优先的 AI 记忆系统，将对话历史存储为逐字文本，用语义搜索检索。不会总结、提取或改写原文。

**核心概念**：
```
┌─────────────────────────────────────────────────────────────┐
│                    MemPalace 记忆架构                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Wing（翅膀）→ 人或项目                                      │
│  Room（房间）→ 话题                                         │
│  Drawer（抽屉）→ 原始内容                                    │
│                                                             │
│  搜索可以限定范围（而不是横扫整个语料库）                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**性能指标**：
| 模式 | R@5 | LLM 需要 | 说明 |
|------|-----|---------|------|
| Raw（纯语义搜索） | **96.6%** | ❌ 无 | 无 API key、无云、LLM 零调用 |
| Hybrid v4（450q 留出测试） | **98.4%** | ❌ 无 | 可泛化的真实指标 |
| Hybrid v4 + LLM rerank | ≥99% | ✅ 任意模型 | 支持 Claude Haiku/Sonnet/minimax-m2.7 |

**安装使用**：
```bash
# 推荐使用 uv
uv tool install mempalace
mempalace init ~/projects/myapp

# 或者 pip
pip install mempalace

# 挖掘内容
mempalace mine ~/projects/myapp                    # 项目文件
mempalace mine ~/.claude/projects/ --mode convos   # Claude Code 会话

# 搜索
mempalace search "why did we switch to GraphQL"

# 为新会话加载上下文
mempalace wake-up
```

**适用场景**：
- Claude Code 会话过期问题（30 天不保存就没了）
- 需要长期记忆的 Agent 项目
- 本地隐私优先，不想让数据上云

### 3. ⭐ h4ckf0r0day/obscura
**一句话**：Rust 写的无头浏览器，内存 30MB vs Chrome 200MB，带反检测

**项目档案**：
- **GitHub**：https://github.com/h4ckf0r0day/obscura
- **Stars**：10,000+ ⭐
- **License**：Apache 2.0
- **技术栈**：Rust + V8

**是什么**：
专为 AI Agent 和网页爬取设计的 Rust 无头浏览器引擎。运行真实 JavaScript，支持 Chrome DevTools Protocol，是无头 Chrome 的替代品。

**性能对比**：
| 指标 | Obscura | 无头 Chrome |
|------|---------|-------------|
| **内存** | **30 MB** | 200+ MB |
| **二进制大小** | **70 MB** | 300+ MB |
| **反检测** | **内置** | 无 |
| **页面加载** | **85 ms** | ~500 ms |
| **启动速度** | **即时** | ~2s |
| **Puppeteer** | ✅ | ✅ |
| **Playwright** | ✅ | ✅ |

**安装使用**：
```bash
# Linux x86_64
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-x86_64-linux.tar.gz
tar xzf obscura-x86_64-linux.tar.gz
./obscura fetch https://example.com --eval "document.title"

# Docker
docker run -d --name obscura -p 127.0.0.1:9222:9222 h4ckf0r0day/obscura

# 从源码编译
git clone https://github.com/h4ckf0r0day/obscura.git
cd obscura
cargo build --release
# 带 stealth 模式（反检测 + 追踪器拦截）
cargo build --release --features stealth
```

**快速开始**：
```bash
# 获取页面标题
obscura fetch https://example.com --eval "document.title"

# 提取所有链接
obscura fetch https://example.com --dump links

# 渲染 JavaScript 并导出 HTML
obscura fetch https://news.ycombinator.com --dump html

# 通过代理
obscura --proxy socks5://localhost:1080 fetch https://example.com
```

**适用场景**：
- AI Agent 需要浏览器自动化
- 网页爬取（不想被检测）
- 替代 Puppeteer/Playwright 的重量级方案

**项目档案**：
- **GitHub**：https://github.com/ultraworkers/claw-code

`claw` CLI agent harness 的公开 Rust 实现。canonical 实现放在 `rust/`，是当前源码的 truth。

**项目结构**：
```

├── rust/              # Rust 工作区 + claw 二进制
```

### 5. ⭐ JuliusBrussee/caveman
**一句话**：让 AI 说话像原始人，砍掉 75% token 输出，技术准确性 100%

**项目档案**：
- **GitHub**：https://github.com/JuliusBrussee/caveman
- **适用 Agent**：Claude Code、Codex、Gemini、Cursor、Windsurf、Cline、Copilot 等 30+ 种

**是什么**：
Claude Code 技能/插件，让 AI 的输出变成"原始人语言"——砍掉 75% token，保持 100% 技术准确性。

**效果对比**：

| 正常 Claude（69 tokens） | Caveman Claude（19 tokens） |
|--------------------------|----------------------------|
| "The reason your React component is re-rendering is likely because you're creating a new object reference on each render cycle. When you pass an inline object as a prop, React's shallow comparison sees it as a different object every time, which triggers a re-render. I'd recommend using useMemo to memoize the object." | "New object ref each render. Inline object prop = new ref = re-render. Wrap in `useMemo`." |

**强度等级**：
- `lite` — 去掉填充词
- `full`（默认）— 完整 caveman 风格
- `ultra` — 电报风格
- `wenyan` — 文言文，最短

**安装**：
```bash
# Claude Code 中安装 skill
/install caveman

# 或参考 INSTALL.md 完整安装
```

**适用场景**：
- Token 成本敏感项目
- 需要快速技术交流
- "废话太多" 的 AI 输出让你崩溃
