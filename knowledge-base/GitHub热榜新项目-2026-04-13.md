## 🔥 重点项目

### 1. OpenHands/OpenHands
**AI-Driven Development · 对标 Devin/Jules**

| 项目 | 说明 |
|------|------|
| **GitHub** | https://github.com/OpenHands/OpenHands |
| **Stars** | 74,380 ⭐ |
| **License** | MIT |
| **文档** | https://docs.openhands.dev |
| **论文** | https://arxiv.org/abs/2511.03690 |

**是什么**：
OpenHands 是一个**AI驱动开发**社区项目，专注于构建 AI Agent 来自动化软件开发任务。对标 GitHub Copilot 的 Jules、Cognition 的 Devin。

**四种使用方式：**

| 产品 | 说明 | 适用场景 |
|------|------|---------|
| **OpenHands SDK** | Python库，可组合的Agent技术 | 代码中定义Agent，本地/云端运行 |
| **OpenHands CLI** | 命令行工具，类似Claude Code/Codex | 终端用户快速上手 |
| **OpenHands Local GUI** | 本地图形界面，类似Devin/Jules | 桌面端用户 |
| **OpenHands Cloud** | 托管版本，免费使用Minimax模型 | 不想自己部署 |
| **OpenHands Enterprise** | 企业版，自托管Kubernetes | 大型企业 |

**核心能力：**
| 能力 | 说明 |
|------|------|
| **SWEBench** | 77.6% 基准分（软件工程任务） |
| **多模型支持** | Claude/GPT/任意LLM |
| **多平台集成** | Slack/Jira/Linear |
| **协作功能** | 对话分享、多用户支持 |
| **RBAC权限** | 企业级访问控制 |

**安装使用：**
```bash
# CLI 模式
# 参考文档：https://docs.openhands.dev/openhands/usage/run-openhands/cli-mode

# Docker 快速启动
docker run -it \
    -e OPENHANDS_API_KEY="your-api-key" \
    -p 3000:3000 \
    openhands/agent-server

# 或者 pip 安装
pip install openhands

# 启动 CLI
openhands
```

**Cloud 免费试用：**
- 地址：https://app.all-hands.dev
- 支持 GitHub/GitLab 登录
- 免费使用 Minimax 模型

### 2. DeepSeek-AI/DeepSeek-V3
**MoE 大模型 · 671B参数 · 37B激活**

| 项目 | 说明 |
|------|------|
| **GitHub** | https://github.com/deepseek-ai/DeepSeek-V3 |
| **Paper** | https://arxiv.org/pdf/2412.19437 |

**核心参数：**

| 参数 | 数值 |
|------|------|
| **总参数量** | 671B |
| **激活参数** | 37B/token |
| **训练数据** | 14.8万亿 tokens |
| **训练成本** | 278万 H800 GPU小时 |

**技术创新：**

| 技术 | 说明 |
|------|------|
| **Multi-head Latent Attention (MLA)** | 高效注意力机制 |
| **DeepSeekMoE** | MoE架构优化 |
| **Auxiliary-loss-free Load Balancing** | 无辅助损失的负载均衡 |
| **Multi-Token Prediction (MTP)** | 多token预测目标 |

**性能表现：**
- 超越其他开源模型
- 与顶级闭源模型性能相当
- 训练过程极其稳定，无不可恢复的loss峰值
