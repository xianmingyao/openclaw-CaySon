## 2. 专家团队生态

### 2.1 Caixa-git/hermes-persona
**172个专家角色 · 15大类别 · 自动匹配**

| 项目 | 说明 |
|------|------|
| **GitHub** | https://github.com/Caixa-git/hermes-persona |
| **角色数** | 172 specialists across 15 categories |
| **核心原理** | 根据任务上下文自动选择最佳专家角色 |

**工作原理：**
```
任务 → 扫描172个角色 → 匹配度>30%? → 采用专家角色
                                  ↓
                            ≤30% → 无角色（通用回退）
```

**选择原则（研究支撑）：**
| 原则 | 参考 |
|------|------|
| 输出类型对齐 — 匹配交付物到任务 | MetaGPT (ICLR 2024) |
| 角色边界清晰 — 恰好一个角色，不重叠 | CAMEL (NeurIPS 2023) |
| 任务分解优先级 — 主域优先 | AgentVerse (ICML 2024) |
| 置信度阈值 — ≤30% → 无角色，避免错配伤害 | AutoGen (2023) |

**安装：**
```bash
bash <(curl -sSL https://raw.githubusercontent.com/Caixa-git/hermes-persona/main/install.sh)
```

**使用：**
```bash
# 聊天中直接使用
use persona

# CLI创建任务
hermes kanban create 'Audit OWASP top 10' --skill persona
hermes kanban assign t_xxxx persona-worker
hermes kanban dispatch
# → 🎭 Security Engineer
```

## 4. 如何使用和部署

### 方式一：快速体验（推荐）

```bash
# 1. 安装 Hermes Agent
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 2. 启动交互式CLI
hermes

# 3. 在对话中使用 persona 技能
use persona
```

### 方式二：完整团队部署

```bash
# 1. 安装 Hermes Agent
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 2. 安装 persona 技能（172专家角色）
bash <(curl -sSL https://raw.githubusercontent.com/Caixa-git/hermes-persona/main/install.sh)

# 3. 安装 C-Suite 团队（8+75专家）
git clone https://github.com/jasonngtb/dream-planners-agency.git ~/.hermes/skills/csuite/

# 4. 配置消息平台（可选：Telegram/Discord等）
hermes gateway setup

# 5. 启动
hermes gateway start
```

### 方式三：特定任务使用

```bash
# 仅使用CEO角色
/skill albert-ceo

# 仅使用CTO（工程部门）
/skill terrence-cto

# 创建审计任务
hermes kanban create 'Audit OWASP top 10' --skill persona
hermes kanban assign t_xxxx persona-worker
hermes kanban dispatch
```

## 5. 技术架构详解

### Hermes Agent 架构

```
┌─────────────────────────────────────────────────────────────┐
│                     Hermes Agent Loop                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 接收输入（CLI/消息平台/定时触发）                          │
│           ↓                                                 │
│  2. 理解任务 + 检索记忆（Honcho用户建模）                     │
│           ↓                                                 │
│  3. 选择工具/技能（Skills系统）                              │
│           ↓                                                 │
│  4. 执行 + 工具调用                                         │
│           ↓                                                 │
│  5. 结果存储 + 技能自改进                                    │
│           ↓                                                 │
│  6. 响应返回                                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 消息网关架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Messaging Gateway                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Telegram / Discord / Slack / WhatsApp / Signal / Email    │
│           ↓                                                 │
│              Single Gateway Process                          │
│           ↓                                                 │
│         Hermes Agent                                         │
│           ↓                                                 │
│         Reply to Platform                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
