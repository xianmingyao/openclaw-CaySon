## 4. 🔌 MCP 生态

awesome-agent-skills 中的许多技能基于 **Model Context Protocol (MCP)**，实现了：

- 🌐 **外部工具集成**：浏览器、数据库、API
- 📊 **数据处理**：CSV、JSON、Excel
- 🔍 **搜索引擎**：网络搜索、代码搜索
- 📝 **文档处理**：PDF、Markdown、代码文档

## 7. 🎬 使用建议

### 新手推荐路径
1. 先装 **mattpocock/skills**（工程基础技能）
2. 再装 **awesome-agent-skills**（按需扩展）
3. 最后定制自己的技能库

### 按需安装
```bash
# 安装特定类别的技能
/claude-code install tdd
/claude-code install security
/claude-code install ml-research
```
