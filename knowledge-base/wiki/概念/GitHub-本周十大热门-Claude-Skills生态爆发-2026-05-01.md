## 4. ✅ 重点项目详解

### core - 开源电脑操作 Agent 基础设施
- **功能**：沙箱 + SDK + Benchmark
- **能力**：可控制全桌面环境
- **意义**：为 AI Agent 提供标准化的电脑操作框架

### genericagent - 自我进化 Agent 框架
- **亮点**：全系统控制 + Token 消耗仅同类 1/6
- **优势**：成本效益极高

### ml intern - Hugging Face ML Agent
- **背景**：Hugging Face 官方出品
- **功能**：自动跑通 ML 研究流水线
- **价值**：让非 ML 工程师也能自动化实验

### Skills - 工程师实战技能包
- **作者**：Matt Pocock
- **定位**：TypeScript 顶流的 Claude Code 技能包
- **内容**：覆盖真实开发高频场景
