**核心定位：**
> "Symphony turns project work into isolated, autonomous implementation runs, allowing teams to manage work instead of supervising coding agents."

**核心特性：**
- 🏛️ **隔离运行**：项目工作变成隔离的自主实现运行

**工程化价值：** 把AI Agent从"工具"变成"团队成员"，团队管理Agent工作而非手动监督

### 2️⃣ JCode - Rust AI编码Agent ⭐ 5.1k

| 项目 | 信息 |
|------|------|
| **Stars** | 5.1k |
| **Forks** | 511 |
| **语言** | Rust 94.2% |
| **定位** | "The next generation coding agent harness to raise the skill ceiling" |
| **链接** | https://github.com/1jehuang/jcode |

**核心定位：** 下一代编码Agent框架，主打极致性能和低内存占用

**性能对比（震惊）：**

| 指标 | JCode | Claude Code | 差距 |
|------|-------|-------------|------|
| **RAM (1 session)** | 167 MB | 387 MB | 2.3× |
| **RAM (10 sessions)** | 261 MB | 2301 MB | 8.8× |
| **首帧时间** | 14.0 ms | 3437 ms | **245×** |
| **首次输入** | 48.7 ms | 3513 ms | **72×** |
| **每新增session** | +10.4 MB | +212.7 MB | 20× |

**结论：** JCode在性能上全面碾压其他AI编码工具，特别适合资源敏感环境

**关键特性：**
- Multi-session支持
- Agent memory
- Swarm多Agent协作
- OAuth登录 + 多Provider支持
- MCP (Model Context Protocol) 客户端
- iOS原生客户端
