# Hackingtool - 一站式黑客工具箱

## 1. 🎯 这是什么

**Hackingtool** 是 GitHub 上集成了 185+ 渗透测试工具的一体化开源框架，由开发者 Z4nzu 维护。提供直观的 TUI 操作界面，支持一键安装、批量更新与 Docker 部署，兼容多系统。

**GitHub**: Z4nzu/hackingtool (⭐ 45k+)
**定位**: 网络安全专家、渗透测试人员、道德黑客

## 4. 🔧 安装与使用

### 快速安装
```bash
# 克隆仓库
git clone https://github.com/Z4nzu/hackingtool.git
cd hackingtool

# 运行
python3 hackingtool.py
```

### Docker 部署
```bash
docker build -t hackingtool .
docker run -it hackingtool
```

### 系统要求
- Kali Linux / Ubuntu / Debian / Fedora
- Python 3.8+
- 需安装部分依赖工具
