# OpenAI Symphony - 智能编排规范

## 1. 🎯 这是什么

**Symphony** 是 OpenAI 于 **2026年3月4日** 开源的**智能编排规范**，核心理念是：

> **"From watching agents code to managing the work itself."**
> (从盯着AI写代码，到管理AI的工作本身)

Symphony 将任务看板（如 Linear）转化为全自动研发流水线，实现从 **Issue 监控 → Codex 编码 → PR 提交** 的闭环自动化。

### 3.2 工作原理

| 阶段 | 说明 |
|------|------|
| **1. Issue监控** | 持续监控 Linear 看板，检测新任务 |
| **2. 任务拆分** | 自动将复杂Issue拆分为可执行任务 |
| **3. Agent生成** | 为每个任务生成独立的 Codex Agent |
| **4. 隔离运行** | 在独立工作区运行，避免冲突 |
| **5. CI检测** | 监控CI流程，验证代码质量 |
| **6. PR提交** | 自动提交Pull Request |
| **7. 结果审核** | 提供完整的工作证明（CI状态+代码审查） |

## 4. ⚡ 核心特性

### 4.1 自动化能力

| 特性 | 说明 |
|------|------|
| **自动拆分研发工单** | 智能拆解复杂Issue |

### 4.2 管理变革

| 传统模式 | Symphony 模式 |
|----------|--------------|
| 人工盯着AI写代码 | AI自主完成，人工管理 |
| 单会话串行执行 | 多任务并行隔离运行 |
| 故障需人工介入 | 故障自动重启重试 |
| 分散的结果 | 统一的PR + 验证报告 |
