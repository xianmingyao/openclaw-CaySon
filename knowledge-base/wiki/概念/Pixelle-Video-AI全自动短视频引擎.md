# Pixelle-Video - AI 全自动短视频引擎

## 1. 🎯 这是什么

**Pixelle-Video** 是由 AIDC-AI 团队开发的 AI 全自动短视频引擎，核心理念是"**让视频创作成为一句话的事**"——用户只需输入一个主题，系统就能自动完成从文案撰写、AI 配图、语音合成、背景音乐到最终视频合成的全部流程。

**GitHub**: AIDC-AI/Pixelle-Video
**官网**: https://aidc-ai.github.io/Pixelle-Video/zh/
**特点**: 零门槛、零剪辑经验、开源免费

---

## 2. 🎬 核心功能

### 自动化流程

```
输入主题 → 文案生成 → 配图规划 → 逐帧处理 → 视频合成
```

| 步骤 | AI 能力 |
|------|----------|
| 📝 文案生成 | 自动撰写视频脚本 |
| 🎨 AI 配图 | 生成与文案匹配的视觉内容 |
| 🗣️ 语音解说 | TTS 语音合成 |
| 🎵 背景音乐 | 自动匹配合适的背景音乐 |
| 🎬 视频合成 | 一键生成完整视频 |

## 4. 🔧 使用方法

### 在线体验
访问 https://aidc-ai.github.io/Pixelle-Video/zh/ 直接体验

### 本地部署
```bash
# 克隆仓库
git clone https://github.com/AIDC-AI/Pixelle-Video.git
cd Pixelle-Video

# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

### 使用示例
```python
# 输入主题
topic = "为什么要养成阅读习惯"

# 一键生成视频
video = generate_video(topic)

# 输出完整视频文件
video.save("output.mp4")
```

## 5. ✅ 优点

- ✅ **零门槛**：不需要任何视频制作经验
- ✅ **全自动化**：从主题到成片一步到位

## 6. ❌ 缺点

- ❌ 生成质量依赖底层 AI 模型
- ❌ 部分功能需要 GPU 加速
- ❌ 复杂主题可能需要手动调整
- ❌ 视频时长有限制
