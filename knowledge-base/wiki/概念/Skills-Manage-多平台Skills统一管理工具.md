# Skills Manage - 多平台 Skills 统一管理工具

## 1. 🎯 这是什么

**Skills Manage** 是开发者 @志辉 开源的桌面应用，核心理念是"**一处编写，多处复用**"。通过中央技能库 + 软链接同步技术，彻底解决多 AI 平台 Skills 管理混乱的难题。

**GitHub**: iamzhihuix/skills-manage
**技术栈**: Tauri 2.0 + React 19 + Tailwind 4
**定位**: Skills 的"应用商店"式管理器

## 3. 🔧 核心功能

### 3.1 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                   Skills Manage (中央库)                      │
│                   ~/.agents/skills/                          │
└─────────────────────────────────────────────────────────────┘
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ Claude   │    │  Codex   │    │  其他    │
    │  Code    │    │    CLI   │    │  平台    │
    │ (软链接) │    │ (软链接) │    │ (软链接) │
    └──────────┘    └──────────┘    └──────────┘
```

### 3.2 核心特性

| 功能 | 说明 |
|------|------|
| **Marketplace** | 内置市场，直接浏览下载 Skills，点一下就装好 |
| **集合管理** | 按用途建 Collection，批量安装到指定平台 |
| **Discover 扫描** | 自动扫描本地磁盘，找出散落的 Skills |
| **中央仓库** | 所有 Skills 集中在 `~/.agents/skills/` |
| **软链接同步** | 各平台通过符号链接指向中央库 |
| **一键导入** | 从 GitHub 直接导入 Skill 仓库 |
| **多平台支持** | Claude Code / Codex / Cursor 等 |
| **可视化编辑** | 内置 Monaco 编辑器 |
| **自动同步** | 修改一次，全平台生效 |
| **仓库导入** | 填来源即导入，带鉴权和自动重试 |
| **大库搜索不卡** | 懒加载 + 虚拟列表 + 延迟去抖 |

### 3.3 设计原则

| 原则 | 说明 |
|------|------|
| **纯本地，无遥测** | 不上传用户行为数据，保护隐私 |
| **网络按需触发** | 只有安装/更新时才联网 |
| **场景切换** | 不同场景使用不同集合 |

## 5. ✅ 优点

- ✅ **一处编写，多处复用** - 真正的 DRY 原则
- ✅ **软链接同步** - 技术简单但高效
- ✅ **多平台兼容** - Claude Code / Codex / Cursor 等
- ✅ **可视化界面** - 比命令行更直观
- ✅ **开源免费** - Tauri 桌面端，体验流畅

---

## 6. ❌ 缺点

- ❌ 跨平台软链接在 Windows 上有限制
- ❌ 需要手动处理冲突
- ❌ 新工具可能需要适配
