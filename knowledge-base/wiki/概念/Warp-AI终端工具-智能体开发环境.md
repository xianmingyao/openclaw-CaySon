# Warp - AI 终端工具 / 智能体开发环境

## 1. 🎯 这是什么

**Warp** 是一个 AI 优先的智能体开发环境（Agentic Development Environment），2026年4月28日宣布开源。Warp 将传统的终端改造为现代的 AI 驱动开发平台，支持内置编码智能体或自带 CLI 智能体（Claude Code、Codex、Gemini CLI 等）。

**GitHub**: warpdotdev/Warp
**官网**: https://www.warp.dev/
**用户数**: 70万+开发者

---

## 2. 📝 核心功能

### 🤖 AI 智能体集成

| 功能 | 说明 |
|------|------|
| **内置编码智能体** | Warp 自带的 AI 编码能力 |
| **Claude Code** | 支持 Anthropic 的 Claude Code |
| **Codex** | 支持 OpenAI 的 Codex |
| **Gemini CLI** | 支持 Google 的 Gemini CLI |
| **自定义 CLI 智能体** | 可接入任何兼容的 CLI 工具 |

### 🖥️ 终端增强

| 功能 | 说明 |
|------|------|
| **智能补全** | AI 驱动的命令补全 |
| **工作流管理** | 团队协作和共享 |
| **云端同步** | 配置和历史跨设备同步 |
| **块编辑** | 以块为单位编辑和复制命令 |

## 4. ✅ 优点

- ✅ **AI 优先设计**：不是事后加 AI，是原生 AI
- ✅ **多智能体支持**：不锁定单一供应商
- ✅ **开源透明**：解决了闭源终端的信任问题

- ✅ **70万+用户**：成熟稳定的产品

## 5. ❌ 缺点
