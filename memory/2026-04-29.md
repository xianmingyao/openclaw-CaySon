## 22:20 jingmai-putaway Skill Bug 修复

### 问题分析
1. **skill执行失败**: UFO Agent 调用 skill runtime 失败
2. **WinError 123**: 截图文件名包含商品名称中的反斜杠 `\`
   - 错误: `before_{'type': 'input', 'text': '公牛（BULL） 插座\B5系列...'}`
3. **SIGKILL**: 进程被系统终止（多次发生）

### 根因确认
1. `_BuiltinProcessor.process()` 中间件调用逻辑错误：
   - 传入 `action` 字典而非 `phase` 枚举
   - `WorkingScreenshotMiddleware` 期望 phase 枚举
2. 特殊字符未过滤：商品名称含 `\` 导致文件名非法

### 修复内容
**文件**: `E:\workspace\skills\jingmai-putaway\jingmai-cli\resources\jingmai_product_publish\scripts\run_skill.py`

1. **phase 类型检查**:
```python
phase_name = getattr(phase, "value", str(phase))
# 当 phase 是字典时，str(phase) = "{'type': 'input', ...}"
# 修复后：检查 phase 是否是有效枚举
```

2. **非法字符过滤**:
```python
# 过滤 Windows 文件名非法字符
illegal_chars = '<>:"/\\|?*'
safe_name = ''.join(c if c not in illegal_chars else '_' for c in str(phase))
```

3. **窗口匹配增强**:
   - `jingmai_locator.py`: 添加 `JD_WORK` 关键字识别京麦窗口
