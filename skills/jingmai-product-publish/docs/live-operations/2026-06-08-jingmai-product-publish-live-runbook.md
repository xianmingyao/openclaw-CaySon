## 1. 核心结论

- 京麦桌面内的 `wares-jdm.jd.com` 页面是 WebView，页面内部控件经常不暴露给 Windows UIA。自动化不能只依赖 `click_text()` 或 UIA 文本查找。
- 多行 Excel 批量上架时，每一行商品都要从 `商品列表 > 草稿箱` 或商品列表页点击 `+发布商品` 新建流程开始，不要在同一个表单里连续改多条数据。
- Excel 中纯数字 `category_id` 或 `上架序号` 不能直接作为类目搜索词。本轮 Excel 中 `category_id=1`，真实类目关键词应从标题或补充字段推断为 `插座`。
- 类目页必须先选中结果，让页面出现 `已选类目：工业品 > 中低压配电 > 插座`，再点击 `下一步，完善其他商品信息`。
- 图文详情为空报错不是只靠 `高级编辑` 区域解决。要切到 `图文编辑`，点击 `添加文本`，把详情文案写入下方 `文本编辑` 输入框，并验证 `已添加 1/50张` 和右侧预览。
- 保存成功的判定不是按钮点击完成，而是页面返回 `商品列表 > 草稿箱`，目标商品出现在列表且修改时间更新。本轮成功草稿商品编码是 `100282053911`。
- 每次真实运行都要保留截图和日志。遇到卡壳先截图，再根据页面状态决定是修坐标、补字段、还是回退到草稿箱重新进入。

## 5. 批量上架总流程

每一行 Excel 商品都按同一套状态机执行。不要跳状态。

| 阶段 | 起始页面 | 目标 | 成功信号 | 失败信号 |
|---|---|---|---|---|
| 读取 Excel | 本地项目目录 | 得到一条商品上下文 | 输出 `row`、`sku`、`category_keyword`、`title` | `category_keyword` 是纯数字或空 |
| 进入发布入口 | 草稿箱或商品列表 | 打开类目选择页 | URL 是 `/ware/categorySelect` | UIA 找不到 `+发布商品` 或页面不跳转 |
| 选择类目 | 类目选择页 | 选中四级类目 | 页面显示 `已选类目`，下一步按钮变蓝 | 只输入搜索词但没有已选类目 |
| 进入表单 | 类目选择页 | 打开商品表单 | URL 是 `vcProductPublish`，页面有基础信息 | 仍停留 `/categorySelect` |
| 填基础信息 | 商品表单顶部 | 标题、品牌、价格、属性齐全 | 必填星号字段有值 | 下拉框看似输入但未选中 |
| 填图文详情 | 图文详情区 | 添加文本详情 | 显示 `已添加 1/50张`，右侧预览有文字 | 报 `商品详情高级编辑内容为空` |
| 填物流售后 | 物流售后区 | 单位、包装、质保、清单齐全 | 必填字段均有值 | `包装清单` 空或下拉未选中 |
| 填 SKU | 规格描述区 | SKU 属性、库存、尺寸、重量、图片齐全 | SKU 行无红字必填提示 | 横向隐藏字段漏填 |
| 保存草稿 | 底部按钮区 | 保存到草稿箱 | 返回草稿箱，修改时间更新 | 仍在表单并出现报错反馈 |

## 6. 类目入口实战步骤

多行 Excel 的关键是每条商品都从新建入口开始。

1. 进入 `商品列表 > 草稿箱`。
2. 点击右上角 `+发布商品`。
3. 等待进入 `https://wares-jdm.jd.com/ware/categorySelect`。
4. 点击类目搜索框。
5. 输入四级类目关键词。本轮为 `插座`。
6. 优先尝试键盘 `Down`，再 `Enter`。
7. 如果键盘没有选中，点击搜索结果行里的 `插座`。
8. 验证页面下方出现 `已选类目：工业品 > 中低压配电 > 插座`。
9. 点击 `下一步，完善其他商品信息`。
10. 等待进入 `vcProductPublish` 页面后停止类目流程。

本轮 2560x1440 最大化窗口下已验证的坐标 fallback:

| 动作 | 坐标 | 说明 |
|---|---:|---|
| 点击 `+发布商品` | `(2160, 174)` | UIA 找不到按钮时使用 |
| 点击类目搜索框 | `(1280, 230)` | `(1280,154)` 实测太高，会点不到输入框 |
| 点击搜索结果 `插座` | `(744, 270)` | 输入关键词后结果出现，再点这行文本 |
| 点击 `下一步` | `(1280, 1314)` | 必须在已选类目出现后再点 |

坐标 fallback 使用规则:

- 先截图确认页面布局、窗口大小和分辨率一致。
- 先尝试 UIA 或语义定位，失败后再用坐标。
- 坐标点击后必须立即截图验证页面是否进入预期状态。
- 页面未变化时不要连续重复点同一个坐标，先重新判断当前页面。

## 8. 图文详情字段补充

本轮第一次保存草稿时出现报错:

```text
商品详情高级编辑内容为空，如已确认完整维护，可点击右侧“绑定商品”模块中手动编辑，或优先使用“图文详情”功能以避免此类报错
```

修复步骤必须按顺序执行:

1. 滚动到 `图文详情` 区域。
2. 切换单选项到 `图文编辑`。不要停留在 `高级编辑`。
3. 点击 `添加文本`。
4. 页面生成文本层后，点击下方实际的 `文本编辑` 大输入框。
5. 粘贴详情文案。
6. 看顶部状态是否从 `已添加 0/50张` 变为 `已添加 1/50张`。
7. 看右侧详情预览是否出现刚粘贴的文案。
8. 再继续保存草稿。

本轮可用详情文案:

```text
公牛（BULL）B5系列新国标插座，8位总控设计，线长1.6米，额定电压250V，适用于家庭、办公等日常用电场景。产品带儿童保护门，符合新国标插座使用要求。包装清单：插座*1，说明书*1。请在额定功率范围内使用，避免潮湿环境和超负荷用电。质保期1年，以平台售后规则为准。
```

图文详情成功信号:

- 页面显示 `已添加 1/50张`。
- 右侧详情预览能看到文本。
- 再保存草稿时不再出现 `高级编辑内容为空` 报错。

不要犯的错误:

- 只点击 `添加文本`，但不在下方输入框写内容。
- 只看高级编辑里的横幅占位图，以为详情已经有内容。
- 修错页面时打开了旧 `draftId`，但当前操作商品在另一个 `applyId`。

## 10. SKU 与规格描述填写矩阵

SKU 区域在页面下方，并且表格横向很宽。很多字段默认不在首屏，需要横向滚动。

| 字段 | 本轮填写值 | 操作经验 | 成功判定 |
|---|---|---|---|
| 商品名称 | 使用商品标题或简化后的同义名称 | 单 SKU 可直接复用标题 | SKU 行商品名称不为空 |
| SKU 属性 | 弹窗配置后显示 `已设置5项` | 点击 `请设置`，按规格属性弹窗配置 | 返回表格后显示已设置数量 |

| 是否厂直商品 | `是` | 页面默认或单选保持 `是` | 单选选中 |
| 短标题 | 建议 `公牛B5系列8位总控插座1.6米` | 不要太长，突出规格 | 字段不为空且无超长提示 |
| 货号 | 可用 SKU 或型号规则 | 本轮可按 `16793098028` 或 `B5440` 填写 | 字段不为空 |
| 包装长(mm) | `250` | 横向滚动到尺寸列 | 字段显示 `250` |
| 包装宽(mm) | `76` | 横向滚动到尺寸列 | 字段显示 `76` |
| 包装高(mm) | `29` | 横向滚动到尺寸列 | 字段显示 `29` |
| 商品毛重(kg) | `0.5` | 横向滚动到重量列 | 字段显示 `0.5` |
| 商品条形码 | Excel 无明确值时可留空 | 非必填时不要造假 | 无红字阻断 |
| 图片设置 | 上传主图和透明图 | 点击 SKU 行右侧 `+ 添加` | 图片区域不再提示 `请上传图片` |

SKU 区域操作顺序建议:

1. 先填 SKU 行 `商品名称`。
2. 点 `SKU属性 > 请设置`，完成弹窗里的规格配置。
3. 填库存和短标题。
4. 横向滚动到货号、尺寸、重量、图片列。
5. 逐项填写尺寸和重量。
6. 最后上传图片。
7. 截图确认没有红色必填提示。

SKU 卡点:

- 页面显示 `SKU总数 1/150` 不代表 SKU 字段都填完，只代表有一行 SKU。
- 表格横向滚动条会遮挡或隐藏字段。找不到 `包装长/宽/高/毛重/图片设置` 时先看横向滚动位置。
- 单 SKU 不一定需要 `批量` 操作，逐项填更稳定。

5. 粘贴本地图片绝对路径，确认选择。
6. 等待上传完成，不要立刻关闭面板。
7. 看图片区域是否从 `请上传图片` 变为已上传缩略图。
8. 截图留证。

图片卡点:

- 文件选择框如果不在前台，粘贴路径会进入京麦页面而不是文件框。
- 只看到占位图或红框，说明图片没有真正上传完成。
- 图片上传后页面可能需要等待几秒，立刻保存可能触发图片未完成校验。

## 12. 保存草稿流程

保存前最终确认:

1. 基础信息必填字段都有值。
2. 图文详情 `图文编辑` 已添加文本层。
3. 物流售后必填字段都有值。
4. SKU 行的库存、属性、短标题、尺寸、重量、图片都有值。
5. 底部按钮区可见。
6. 明确只点击 `保存草稿`，不点击 `发布商品`。

保存草稿步骤:

1. 滚动到底部或让底部固定按钮区可见。
2. 找到 `保存草稿` 按钮。它通常在 `发布商品` 旁边。
3. 点击 `保存草稿`。
4. 如出现下拉或确认层，选择保存草稿相关选项，不选择发布。
5. 等待页面跳转。
6. 成功后应回到 `商品列表 > 草稿箱`。
7. 在草稿箱第一行确认标题、商品编码、修改时间。

本轮成功判定:

```text

修改时间: 2026-06-08 02:46:09
页面: 商品列表 > 草稿箱
```

保存失败处理:

- 如果左侧出现 `报错反馈`，先读完整报错文本，再修字段。
- 如果停留表单无反馈，先截图，再看日志是否有异常。
- 不要因为保存失败就点击 `发布商品`。发布按钮不是保存按钮的替代。

## 13. 卡壳排障 Playbook

| 卡壳现象 | 判断依据 | 真实原因 | 修复动作 | 修复后证据 |
|---|---|---|---|---|
| 找不到 `+发布商品` | 日志出现 `control text '发布商品' not found` | WebView 内按钮不暴露给 UIA | 截图确认位置后用坐标 `(2160,174)` | 进入 `/ware/categorySelect` |
| 类目搜索框没输入内容 | 搜索词为空，页面无变化 | 坐标点高了 | 搜索框坐标从 `(1280,154)` 改为 `(1280,230)` | 搜索框出现 `插座` |
| 输入 `插座` 后下一步仍不可用 | 没有 `已选类目` | 只搜索，未选中结果 | 点击结果行 `(744,270)` | 显示 `已选类目` |
| 点击下一步后仍在类目页 | URL 仍是 `/categorySelect` | 未选类目或按钮未点中 | 先选中类目，再点 `(1280,1314)` | URL 变为 `vcProductPublish` |
| 类目关键词变成 `1` | 日志或输入框显示 `1` | 误把 `category_id` 当关键词 | 使用标题推断 `插座`，或 Excel 增加 `category_keyword` | 搜索到插座类目 |
| 图文详情保存报空 | 报错反馈说高级编辑内容为空 | 没有维护图文详情文本层 | 切 `图文编辑`，添加文本并粘贴文案 | `已添加 1/50张` |
| 添加文本后仍报空 | 页面有空文本层但无预览文字 | 只建层，没有写入文本 | 点击下方 `文本编辑` 输入框再粘贴 | 右侧预览有文本 |
| SKU 图片仍红字 | `图片设置` 处仍提示上传 | 图片选择或上传未完成 | 重新打开图片面板，确认文件框前台并等待上传完成 | 缩略图出现 |
| 找不到尺寸字段 | 首屏只看到商品名称、SKU 属性等 | SKU 表格横向滚动隐藏字段 | 拖动横向滚动条到尺寸列 | 看到 `包装长/宽/高/毛重` |
| 保存后不知道是否成功 | 页面跳转但未核对列表 | 没有建立成功判定 | 回草稿箱看第一行商品编码和修改时间 | 编码 `100282053911`，时间更新 |

排障优先级:

1. 先看当前 URL 和页面标题，确认自己在哪个页面。
2. 再看截图，确认控件是否真的可见。
3. 再看日志，确认自动化失败在哪个定位或点击步骤。
4. 最后再改代码或坐标。

- Excel 中纯数字类目值要视为不可靠搜索词，优先使用显式 `category_keyword`，没有时从标题词典推断。

## 17. 后续优化建议

- Excel 模板增加明确字段 `category_keyword`，不要长期依赖标题推断。
- 坐标 fallback 配置化，绑定分辨率、窗口位置和页面类型。
- 增加页面像素检查，自动判断是否在草稿箱、类目页、表单页。
- 图文详情填充做成独立步骤，保存前强制验证 `已添加 1/50张`。
- SKU 横向字段做截图辅助定位，避免尺寸、重量、图片字段漏填。
- 保存草稿后自动读取草稿箱第一行，比较 SKU、标题和修改时间，减少人工确认成本。
