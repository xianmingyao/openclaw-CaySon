# 京麦实战技能调教培训教材：row5 保存草稿复盘

日期：2026-06-09
场景：从 `公牛上架.xlsx` 执行 row5 京麦真实保存草稿，不点击发布商品。

## 目标边界

本教材用于训练后续京麦实战 Agent：遇到京麦 CEF/WebView 表单输入不稳定时，如何按 Vobcoding/技能流程推进，如何选择 fallback，如何在卡住时不误点、不误判成功。

硬边界：

- 真实操作只允许保存草稿。
- 不点击 `发布商品`。
- 每次关键动作后必须截图或读回验证。
- WebView 内部 HTML 控件不能假设 UIA 可直接控制。
- 京麦窗口必须在前台；焦点丢失时立即停止。

## 推荐技能命令顺序

### 1. `/brainstorming`

用途：开局先澄清真实阻塞点，不直接写自动化。

本轮关键判断：

- 京麦表单输入失效表现是“点击无反应/无光标”，不是单纯 Session 0/1 隔离问题。
- 京麦内部 CEF 没有稳定 DOM/CDP 暴露，不能把 WebView 当普通网页自动化。
- A 方案保留 UFO/UIA/Win32/WinCOM 原生控件层；WebView HTML 控件走截图/OCR/坐标/剪贴板 fallback。

训练要求：

- 先问“表现是哪一种”，不要直接上点击脚本。
- 先识别是否可走原生控件层，不能一开始就盲坐标。
- 如果用户要求真实操作，必须确认 `保存草稿` 和 `不发布` 边界。

### 2. `/plan-eng-review`

用途：把实战计划压成可执行步骤和验收标准。

本轮推荐计划模板：

1. 读取项目 `VOBFLOW.md`、`SKILL.md`、live runbook。
2. 解析 Excel，确认真实行数、类目、价格、库存、型号。
3. 先干 row5 单行，不批量。
4. 每一段动作后截图验证。
5. row5 成功保存草稿后，再复制流程到 row6-row10。

验收标准：

- 草稿箱出现 row5 商品。
- 编辑时间为本次操作时间。
- 页面 URL 回到 `wareList?...activeTab=DraftWare`。
- 未点击 `发布商品`。

### 3. `/investigate`

用途：处理卡壳问题，而不是继续扩大动作范围。

本轮典型卡点：

- CEF 内部表单无法 UIA 读 DOM。
- 下拉枚举不能直接粘贴后回车。
- 销售单位没有 `个`，需要搜索/选择平台枚举。
- 图片上传不是系统文件框直达，而是先进入京麦图片空间。
- 危险品字段实际是危险类型多选，不能为了通过校验乱勾选危险品。

调查顺序：

1. 截图确认前台窗口。
2. 判断当前页面区域。
3. 先点一次入口并截图，不连续盲点。
4. 看见下拉/弹窗后再选择具体策略。
5. 如果错误来自平台枚举，优先用平台现有枚举，不强塞 Excel 原值。

### 4. `/qa`

用途：做真实动作后的验证闭环。

本轮 QA 方式：

- 每段动作后生成截图到 `data/screenshots/`。
- 保存草稿后，确认草稿箱第一条为 row5 商品。
- 校验编辑时间：`2026-06-09 02:03:07`。
- 确认不是商品审核页或发布成功页。

关键证据：

- `data/screenshots/live_row5_after_save_draft_click_20260609_020310.png`

### 5. `/review`

用途：复盘风险与误操作可能。

重点审查：

- 是否误点 `发布商品`。
- 是否在 PyCharm/其他窗口前台时继续点击。
- 是否把“点击了”当成“成功了”。
- 是否把 WebView HTML 控件当 UIA 原生控件。
- 是否为通过校验选择了不真实的危险品类型。

### 6. `/do`

用途：沉淀实战记忆。

应记录内容：

## 本轮避坑选择

### 避坑 1：不要把 WebView 当浏览器 DOM

现象：

- UIA 只能读到京麦壳层、地址栏、Chrome/CEF 外层控件。
- 表单内部 HTML 控件无法稳定用 UIA 操作。

正确做法：

- 原生窗口、文件选择器、地址栏走 UIA/Win32/WinCOM。
- WebView 内部表单走截图、坐标、剪贴板、下拉截图验证。
- 每一步动作都保存截图。

### 避坑 2：前台窗口不是京麦时立即停止

每个动作脚本前必须检查：

```python
import ctypes
from ctypes import create_unicode_buffer

user32 = ctypes.windll.user32
hwnd = user32.GetForegroundWindow()
buf = create_unicode_buffer(512)
user32.GetWindowTextW(hwnd, buf, 512)
if "jd_465d1abd3ee76" not in buf.value:
    raise SystemExit("ABORT: Jingmai is not foreground")
```

目的：

- 防止焦点切到 PyCharm、终端、微信后继续点击。
- 防止坐标动作落到错误应用。

### 避坑 3：下拉框不能假设输入即选择

本轮发现：

- 一些 Ant/CEF 下拉框可以搜索，但 `Ctrl+V + Enter` 不一定选中。
- 必须看到候选项，再点击候选项。

有效策略：

1. 点击下拉框。
2. 粘贴搜索词。
3. 截图确认候选项。
4. 点击候选项。
5. 截图确认字段显示选中值。

示例：

- `销售单位` 搜索 `套`，候选出现后点击，字段显示 `套`。
- `特殊发货时效标记` 打开后选择 `普通品`。

### 避坑 4：平台枚举优先于 Excel 字面值

本轮冲突：

- Excel/标题真实规格是 `30米`。
- 插座类目的 `电线长度` 下拉可见枚举没有 `30米/50米`。
- 用户坚持插座类目并授权用 `6米`。

正确记录方式：

- 表单字段按平台枚举选 `6米`。
- 商品标题和详情仍保留真实 `30米3*2.5`。
- 该冲突必须在操作记录中留痕，不能静默吞掉。

### 避坑 5：危险品字段不能乱勾

字段名称是 `是否危险商品`，但实际弹出的列表是危险类型多选：

- 爆炸品
- 压缩液化气体
- 易燃液体
- 自燃物品及遇湿易燃物品
- 氧化剂和有机过氧化物
- 毒害品和感染性物品
- 放射性物品
- 腐蚀品

电缆盘不是这些危险类型。

正确策略：

- 不为了消红星乱勾危险项。
- 保存草稿时让平台校验决定是否必须填。
- 本轮结果：未勾危险类型也保存草稿成功。

### 避坑 6：图片上传不是直接文件框

本轮流程：

1. 点击 SKU 行 `图片设置` 的 `添加`。
2. 进入 `SKU图片设置` 页。
3. 点击方图槽位 `+`。
4. 打开京麦图片空间弹窗。
5. 点击右上 `本地上传`。
6. Windows `打开` 文件框出现。
7. 粘贴本地图片路径。
8. 点击 `打开`。
9. 图片空间出现新图且显示选中。
10. 点击 `确定`。
11. 回到 SKU 表格，缩略图可见。

## 卡壳策略

### 卡壳：鼠标滚轮不滚页面

处理：

- 先点主表单区域，再用 `PageDown`。
- 如果内层滚动不起作用，换坐标点击具体 Tab 或可见入口。
- 不要连续滚动导致页面状态不可追踪。

### 卡壳：下拉没有目标值

处理：

- 先截图保留可见枚举。
- 尝试搜索。
- 如果搜索无结果，不强塞字符串。
- 选择平台允许且业务最接近的值，并在记录中说明。

本轮示例：

- `电线长度` 没有 `30米`，用户授权后选 `6米`。
- `销售单位` 未直接看到 `个/台`，搜索并选中 `套`。

### 卡壳：点击上传没有文件框

处理：

- 判断是否进入平台内嵌图片空间。
- 寻找 `本地上传` 入口。
- 只有 Windows `打开` 前台后，才粘贴本地文件路径。

### 卡壳：保存草稿后不知道是否成功

不要只看按钮点击结果。

必须确认：

- URL 是否进入草稿列表。
- 草稿箱 Tab 是否选中。
- 列表第一条是否为本次商品标题。
- 编辑时间是否是本次操作时间。
